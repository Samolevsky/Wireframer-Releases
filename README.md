# Wireframer

Turn 3D models (STL, OBJ, GLTF, GLB) into wireframes, halftones, stippling, contour lines, pixel art and more, then export them as SVG or PNG. Use it on the web at **[wireframer.samolevsky.com](https://wireframer.samolevsky.com)** or install the desktop app.

## Download

Get the latest version from **[Releases › Latest](https://github.com/Samolevsky/Wireframer-Releases/releases/latest)**:

| Platform | File |
| --- | --- |
| macOS, Apple Silicon (M1 and later) | `Wireframer-<version>-mac-arm64.dmg` |
| macOS, Intel | `Wireframer-<version>-mac-intel.dmg` |
| Windows 10/11 (64-bit) | `Wireframer-<version>-win-x64.exe` |

The macOS app is signed and notarized by Apple. The Windows installer isn't code-signed yet, so on first install Windows may show "Windows protected your PC": click **More info › Run anyway**.

## Updating

Wireframer checks for updates when it starts. You can also check any time with **Wireframer › Check for Updates…** on macOS or **Help › Check for Updates…** on Windows. Accept the update, and it installs the next time the app restarts. Your settings and license are kept.

Versions older than 0.4.9 can't update themselves. Download the new installer once from the link above and install it over the old copy.

**Help › Release Notes** in the app opens the list of releases with what changed in each version.
